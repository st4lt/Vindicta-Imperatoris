<h1> Vindicta Imperatoris </h1>

<h2> Project Description </h2>
Individual final project for the 9th grade. This is a 3D game in the genre of gladiator fights, developed using Python and the Ursina engine. <br>
The game is inspired by the history of the Roman Empire in 105 BC and tells the story of General Ferox Victorian, sent to gladiator battles by order of Emperor Commodus.

<h2> Current Status: [WIP] </h2>
The project is under active development. The basic game mechanics are implemented, the game is functional but requires refinement: <br>
*   Character animations are missing. <br>
*   The interface and sound design need work. <br>

<h2> Controls </h2>
* W/A/S/D: Character movement. <br>
* Mouse (movement): Camera/character rotation. <br>
* Left Mouse Button: Attack. <br>
* Right Mouse Button (hold): Blocking attacks. <br>
* Escape: Open/close pause menu.<br>
